# Calendar Weeks

A lightweight Windows calendar that stays in the notification area and shows the ISO 8601 week number for the selected date.

## Run

Install [uv](https://docs.astral.sh/uv/) and run `run_calendar.bat`. It creates the project environment on the first run, then starts the app without a console window. The tray menu provides **Abrir calendario** and **Salir**.

## Start with Windows

Create a shortcut to `run_calendar.bat` in the current user's Startup folder (`shell:startup`). The shortcut is specific to this checkout and is not included in the repository.
